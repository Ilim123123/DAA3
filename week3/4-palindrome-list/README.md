# 4. Palindrome Linked List

## 1. Problem
Проверить, является ли односвязный список палиндромом.

## 2. Approach
1. Находим середину двумя указателями (`slow` и `fast`).
2. Разворачиваем вторую половину списка.
3. Сравниваем элементы первой и второй половины.

## 3. Time & Space Complexity
- **Time Complexity:** O(n)
- **Space Complexity:** O(1)

## 4. Reflection / Improvement
Простой способ — переписать элементы в массив и сравнить, но он требует O(n) памяти. Разворот списка на месте оптимальнее.
