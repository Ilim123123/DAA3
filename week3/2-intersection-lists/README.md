# 2. Intersection of Two Linked Lists

## 1. Problem
Найти узел, в котором пересекаются два односвязных списка.

## 2. Approach
Используем 2 указателя. Первый идет по списку A, затем переходит на B. Второй идет по B, затем переходит на A. Так они проходят одинаковую суммарную длину и встречаются в точке пересечения.

## 3. Time & Space Complexity
- **Time Complexity:** O(m + n) — проход по обоим спискам.
- **Space Complexity:** O(1) — память фиксирована.

## 4. Reflection / Improvement
Можно было использовать HashSet, но это потребовало бы O(n) памяти. Данный вариант лучше.
