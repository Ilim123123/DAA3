# 1. Remove Duplicates from Sorted List

## 1. Problem
Дано начало отсортированного связного списка. Нужно удалить все повторяющиеся элементы, чтобы каждое значение встречалось только один раз.

## 2. Approach
Список уже отсортирован, поэтому одинаковые элементы стоят друг за другом. 
Мы создаем указатель `current`, который идет от головы списка. Сравниваем текущий элемент со следующим. Если они равны — меняем ссылку `current.next` на следующий за ним элемент.

**Трассировка (Пример: 1 -> 1 -> 2):**
1. `current` на 1. `1 == 1` -> меняем ссылку на 2. Список: `1 -> 2`.
2. `current` на 2. Следующего нет -> конец цикла.

## 3. Time & Space Complexity
- **Time Complexity:** O(n) — проходим по списку один раз.
- **Space Complexity:** O(1) — не задействуем дополнительную память.

## 4. Reflection / Improvement
Решение является оптимальным по времени и памяти.
