# 3. Remove Linked List Elements

## 1. Problem
Удалить все узлы связного списка, значения которых равны `val`.

## 2. Approach
Используем фиктивный узел `dummy` перед головой списка, чтобы корректно обработать случай, когда нужно удалить сам первый элемент.

## 3. Time & Space Complexity
- **Time Complexity:** O(n)
- **Space Complexity:** O(1)
